Install Procwatch

$ curl -fsSL https://raw.githubusercontent.com/chari-dev/procwatch/main/install.sh | sh

Paste that in Terminal. The script installs the tool, schedules the recorder every 30 seconds, and builds the menu bar app if swiftc is available. Nothing needs sudo.

Prefer to read it first: install.sh. Or clone the repository and run sh install.sh. Every build is on the releases page.
